# Серверное приложение "Explore With Me"

## Основной сервис
Основной сервис предоставляет пользователям возможности для поиска и публикации событий, просмотра информации о мероприятиях и подачи заявок на участие. API основного сервиса разделён на три части:
- Публичная — доступна всем пользователям без регистрации и авторизации;
- Закрытая — доступна только авторизованным пользователям;
- Административная — предназначена для администраторов сервиса.

### Публичная часть основного сервиса
Публичный API предоставляет возможности поиска, фильтрации и просмотра событий:
- Список событий можно сортировать по количеству просмотров, получаемому из сервиса статистики, или по дате проведения мероприятия;
- При получении списка событий возвращается краткая информация о каждом мероприятии;
- Пользователи могут получать список доступных категорий и просматривать подборки событий, сформированные администраторами сервиса;
- Каждый публичный запрос для получения списка событий или полной информации о мероприятии фиксируется сервисом статистики.

### Закрытая часть основного сервиса
Закрытый API предоставляет авторизованным пользователям возможности для управления собственными мероприятиями и работы с заявками на участие:
- Создание, редактирование и просмотр собственных мероприятий;
- Подача заявок на участие в интересующих мероприятиях;
- Подтверждение создателем мероприятия заявок, отправленные другими пользователями.

### Административная часть основного сервиса
Административный API предоставляет возможности настройки и поддержки работы сервиса:
- Создание, изменение и удаление категорий для событий;
- Создание и удаление подборок мероприятий, а также управление их отображением на главной странице;
- Модерация мероприятий, опубликованных пользователями: публикация или отклонение;
- Управление пользователями: добавление, активация, просмотр и удаление учётных записей.

## Сервис статистики
Собирает информацию о количестве обращений пользователей к спискам событий и подробной информации о мероприятиях. На основе собранных данных формируется статистика популярности событий.

## Технологический стек
В проекте используются следующие технологии:
- Java — язык программирования, используемый для реализации серверной бизнес-логики;
- Spring Boot — фреймворк для разработки серверной части приложения;
- Maven — инструмент для сборки проекта и управления зависимостями;
- Hibernate - фреймворк для работы с реляционной базой данных;
- PostgreSQL — реляционная система управления базами данных, предназначенная для хранения и обработки данных приложения;
- Docker — платформа контейнеризации, упрощающая развёртывание и запуск сервисов;
- Docker Compose — инструмент для совместного запуска сервисов в контейнерах.

## Архитектура приложения
Приложение состоит из двух взаимодействующих сервисов: основного сервиса и сервиса статистики. Взаимодействие между сервисами осуществляется через REST API по протоколу HTTP. Основной сервис передаёт в сервис статистики информацию об обращениях пользователей, а также получает данные о просмотрах событий, необходимые для сортировки результатов поиска. Для хранения данных каждый сервис использует отдельную базу данных PostgreSQL. Такое разделение позволяет изолировать данные и ответственность сервисов.

## Требования для запуска
- JDK 21
- Docker
